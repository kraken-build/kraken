# Overview

The `kraken.core` provides the agnostic core primitives that make up the Kraken build system. The most notable
members of this module are

- [`Context` class][kraken.core.system.context.Context]
- [`Project` class][kraken.core.system.project.Project]
- [`Task` class][kraken.core.system.task.Task]
- [`Property` class][kraken.core.system.property.Property]
- [`Address` class][kraken.core.address.Address]

The large majority of members implemented in the `kraken.core.*` modules are available to import from the
`kraken.core` module.
